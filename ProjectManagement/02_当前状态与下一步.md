## What Is Working

- Area picker is the user-level control room.
- `orchestration/run_pipeline.py` is the full pipeline orchestrator.
- Data acquisition/cache, cleaning, Houdini-ready manifest, and Houdini preflight are physically separated.
- Coordinate authority lives in `Scripts/shared/vc_geo.py`.
- Semantic contract lives in `Scripts/shared/vc_schema.py`.
- Houdini SOP code is externalized in `Scripts/houdini_sops/`.
- Model QA checks terrain density, building color/normals/foundation/bevel, road surface topology, road profile attrs, and terrain fit.
- Road output currently uses `road_capsule_surface_preview -> road_surface_color -> merge_all / OUT_city`.

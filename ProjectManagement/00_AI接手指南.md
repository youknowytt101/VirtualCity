# 00 AI 接手指南

Last updated: 2026-06-24

## 一句话目标

VirtualCity 要做的是一条可复现的虚拟城市资产管线，不是一次性地图 Demo：

```text
真实地图数据 -> 数据清洗和语义契约 -> Houdini 程序化生成 -> Model QA -> 人工审核 -> UE5 出口
```

## 当前阶段

当前阶段是 `houdini_quality_iteration`。

当前不是最终 UE5 展示阶段。最重要的工作是让这段链路稳定：

```text
数据获取 / 缓存
-> 数据清洗 / 数据 QA
-> Houdini 自动构建
-> Model QA
-> Houdini OUT_city 人工审核
```

## 当前不做

- 不复刻完整 City Sample。
- 不先做大型插件平台。
- 不先做整城/全国级数据。
- 不把 UE5 export/import 放进默认全流程终点。
- 不用当前浏览器 UI 的视觉包装倒推工程目标。
